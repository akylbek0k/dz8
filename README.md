# 🎸 Spotify Band — Портал Рок-группы и Личный Кабинет Музыканта (TypeScript + React)

Домашнее задание №8: Веб-сайт для рок-группы в фирменном стиле **Spotify** с регистрацией, авторизацией, профилем музыканта, плашкой загрузки и деплоем на **GitHub Pages** через **GitHub Actions**.

Проект разработан на **TypeScript** и **React 18** без Babel с использованием высокопроизводительного сборщика **Vite** и нативного компилятора **SWC**.

---

## 🚀 Особенности и Реализованный Функционал

### 1. Аутентификация и Сессии
- **Регистрация музыканта (`POST /api/register/`)**:
  - Валидация логина по регулярному выражению OpenAPI: `^[\w.@+-]+$` (до 150 символов).
  - Валидация пароля (минимум 6 символов).
  - Автоматическое создание карточки музыканта в рок-группе.
- **Вход в систему (`POST /api/login/`)**:
  - Сессионная аутентификация через `Cookie: sessionid=...` (`SameSite=None; Secure`, `credentials: 'include'`) и резервный заголовок `Session-Id`.
  - Модальное окно входа и регистрации в стиле Spotify.
- **Выход из системы (`POST /api/logout/`)**:
  - Полный выход с аннулированием сессии на сервере и очисткой локального хранилища.

### 2. Личный Кабинет Музыканта (Просмотр и Редактирование Профиля)
- **Получение профиля (`GET /api/profile/`)**:
  - Загрузка ID, логина, имени, специализации, биографии и ставки гонорара.
- **Редактирование профиля (`PATCH /api/profile/`)**:
  - Изменение имени (`first_name`, до 100 символов).
  - Выбор специализации (`specialization`) из динамического выпадающего списка, загружаемого через `GET /api/specializations/`:
    - 🎤 *Вокал* (`vocals`)
    - 🎸 *Гитара* (`guitar`)
    - ⚡ *Бас-гитара* (`bass`)
    - 🥁 *Ударные* (`drums`)
    - 🎹 *Клавишные* (`keys`)
    - 🎵 *Другое* (`other`)
  - Редактирование биографии музыканта (`bio`).
  - Управление ставкой за выступление (`fee`, формат с валидацией `^-?\d{0,8}(?:\.\d{0,2})?$`).
  - Адаптивные аватары с динамическим цветовым кодированием в зависимости от инструмента.

### 3. Индикация Сети ("Плашка загрузки")
- Фирменная анимированная верхняя линия загрузки Spotify Green в момент выполнения запросов к API.
- Плавающая плашка-индикатор с пульсирующим свечением, вращающимся спиннером и информативным текстом текущего действия (*"Вход в систему..."*, *"Регистрация музыканта..."*, *"Синхронизация профиля..."*, *"Сохранение изменений..."*).

### 4. Дизайн в стиле Spotify
- **Цветовая палитра**: глубокий черный `#000000`, базовый `#121212`, карточки `#181818`, ховер `#282828` и фирменный зеленый `#1db954` / `#1ed760`.
- **Левый сайдбар (Sidebar)**:
  - Логотип рок-группы с иконкой звуковых волн Spotify.
  - Навигация: *Главная страница группы*, *Участники бэнда*, *Мой профиль*.
  - Раздел дискографии и альбомов группы (*Highway of Dreams*, *Live at Wembley*, *Acoustic Tapes*).
  - Ссылка на документацию Swagger API.
- **Верхняя панель (Navbar)**:
  - Кнопки навигации вперед/назад.
  - Индикатор подключения к бэкенду (с возможностью быстрой смены адреса).
  - Пилл авторизованного музыканта с аватаром, именем и бейджем роли.
  - Кнопки входа и быстрой регистрации для гостей.
- **Главная страница артиста (Artist Hero)**:
  - Баннер рок-бэнда *THE ELECTRIC SHADOWS* с бейджем «Подтвержденный рок-бэнд», миллионной статистикой прослушиваний и кнопкой подписки.
  - Список популярных рок-треков с счетчиком прослушиваний и длительностью.
  - Интерактивная витрина музыкантов группы с выделением карточки текущего вошедшего пользователя (*«★ ВЫ В ГРУППЕ»*).
  - Афиша предстоящего концертного тура 2026.
- **Нижний аудиоплеер (Spotify Player Bar)**:
  - Обложка текущего трека, название композиции, исполнитель и кнопка добавления в избранное (лайк).
  - Кнопки Play/Pause, Shuffle, Previous, Next, Repeat.
  - Живая шкала воспроизведения с таймером и интерактивным скруббером.
  - Регулятор громкости.

### 5. Готовность к смене бэкенда ("бэк агай даст потом")
- В правом верхнем углу (нажатием на пилл `API: ...`) доступно модальное окно **«Настройка API Бэкенда»**.
- Позволяет на лету изменить базовый URL бэкенда, протестировать связь через `GET /api/specializations/` или в 1 клик сбросить к оригинальному Swagger `https://inai-col2.fishrungames.com`.

## 🛠️ Локальный запуск и сборка

### Требования
- Node.js 18+ (рекомендуется LTS 20 или 22)
- npm

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере локальный адрес (обычно `http://localhost:5173/`).

### 3. Проверка типов и сборка для production
```bash
npm run build
```
Готовая статическая сборка будет сгенерирована в директории `dist/`.

### 4. Предпросмотр собранного бандла
```bash
npm run preview
```

## 🌐 Деплой на GitHub Pages через GitHub Actions

В проекте уже настроен файл рабочего процесса: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### Инструкция по публикации:
1. Создайте репозиторий на GitHub (например, `dz8`).
2. Привяжите локальный репозиторий и отправьте код в ветку `main`:
   ```bash
   git remote add origin https://github.com/<ваш-логин-github>/dz8.git
   git branch -M main
   git push -u origin main
   ```
3. Откройте страницу репозитория на GitHub:
   - Перейдите в **Settings** ➔ **Pages**.
   - В блоке **Build and deployment**:
     - В выпадающем списке **Source** выберите **GitHub Actions**.
4. После пуша GitHub Actions автоматически запустит сборку TypeScript и развернет сайт на GitHub Pages по адресу:
   `https://<ваш-логин-github>.github.io/dz8/`

## 📚 Спецификация Backend API

Проект полностью интегрирован со спецификацией **Swagger**:  
URL: [https://inai-col2.fishrungames.com/api/docs/](https://inai-col2.fishrungames.com/api/docs/)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/api/register/` | Регистрация нового музыканта (логин + пароль) |
| `POST` | `/api/login/` | Авторизация пользователя и выдача сессии |
| `POST` | `/api/logout/` | Завершение сессии текущего пользователя |
| `GET` | `/api/profile/` | Получение профиля текущего музыканта |
| `PATCH` | `/api/profile/` | Частичное обновление данных профиля |
| `GET` | `/api/specializations/` | Список доступных инструментов/специализаций |
